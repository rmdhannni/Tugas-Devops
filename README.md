## Struktur Repository

```text
Tugas-Devops/
```

## Navigasi

- **Laporan:** dokumentasi Markdown berada di folder [laporan](laporan/).
- **Aset:** tangkapan layar dan gambar pendukung berada di folder [assets](assets/), dipisahkan berdasarkan bab.
- Setiap laporan menggunakan tautan relatif ke aset agar gambar tetap tampil di GitHub.
