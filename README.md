# Dokumentasi Praktikum DevOps

Repository ini berisi laporan praktikum Workshop DevOps BAB 1–6 beserta bukti dokumentasi berupa tangkapan layar.

## Struktur repository

```text
.
├── assets/
│   ├── BAB-1/
│   ├── BAB-2/
│   ├── BAB-3/
│   ├── BAB-4/
│   ├── BAB-5/
│   └── BAB-6/
└── laporan/
    ├── BAB-1.md
    ├── BAB-2.md
    ├── BAB-3.md
    ├── BAB-4.md
    ├── BAB-5.md
    └── BAB-6.md
```

## Pengelolaan aset gambar

Seluruh gambar disimpan terpisah di dalam `assets/` dan dikelompokkan berdasarkan bab. Referensi gambar pada setiap file laporan menggunakan path relatif menuju folder aset masing-masing, sehingga gambar tetap dapat ditampilkan langsung pada GitHub.

Nama file dan isi dokumentasi gambar dipertahankan agar urutan bukti pada laporan tidak berubah.
